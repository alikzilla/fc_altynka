# Оптимизация чтения матча — 7 ноября 2026

Ветка `codex/optimize-match-reads`, локальные изменения. Рабочая версия и тариф
Cloudflare не менялись.

`eventDetail` один раз загружает матч, очередь и составы. Формирование игрового
протокола использует те же данные. Оплата переиспользует найденный счёт и данные
участников; удалено неиспользуемое чтение матча. Рейтинги используют уже загруженных
пользователей. Получатели и должники вне очереди дочитываются по недостающим ID.
Существующие самостоятельные функции загрузки сохранены; общего кэша нет.
Авторизация и проверки членства не изменялись.

новой сборки. Полные JSON-ответы сравнены через deepEqual с фиксированным временем.
Все восемь сочетаний четырёх маршрутов и двух ролей возвращают одинаковые DTO и 200.

Маршруты игрового протокола, ленты и профиля сохранили ответы и число запросов.
Снимок закрытого матча включает опрос и оплату; бюджет других состояний отличается.

## Проверки

- Исходные 313 тестов Worker прошли до изменения.
- Регрессионные проверки полного чтения матча сначала упали: 6 чтений для
  назначенного матча, 5 для остальных проверенных состояний вместо ожидаемого 1.
- Проверки пользователей сначала упали: 3/2 SELECT вместо 1, а для внешнего
  получателя 3 SELECT вместо 2.
- После исправления проходят 10 новых runtime-тестов, включая scheduled/playing/
  finished/legacy, роли, отсутствие/чужую группу, свежесть имени/телефона,
  внешнего получателя и устаревшие составы после изменения очереди.
- `pnpm test`: core 41, miniapp 205, worker 323 — всего 569.
- `pnpm typecheck`: все три пакета прошли.
- `wrangler deploy --dry-run`: Worker успешно упакован, 1373.03 KiB / gzip
  245.50 KiB; загрузки в production нет.
- `git diff --check`: без ошибок.

Независимое read-only ревью: Critical/Important замечаний нет. Отмечен
некритичный пробел покрытия: частично заполненный knownUsers при более 30
участниках не проверен отдельным новым тестом. Существующий тест больших групп
проверяет самостоятельный вызов рейтингов, новые тесты — полный набор участников
и отсутствующего в нём получателя. Дополнительный тест частичного набора
между несколькими чанками оставлен как последующее улучшение покрытия.
Название одного теста свежести шире его проверок: сам тест меняет профиль;
изменение очереди/устаревание составов проверяется отдельным сценарием.

Решения: используются явные снимки данных в одном запросе вместо общего кэша.
Работа выполнена в исходном чистом checkout на отдельной ветке; слияния,
коммита, push и публикации нет. Эквивалентность при конкурентных изменениях внутри
одного ответа не обещается: ни исходная, ни новая реализация не использует транзакцию
для всего DTO. Свежесть между последовательными запросами проверена.

Локальные приватные артефакты: `artifacts/match-profile/comparison-summary.json`,
`comparison-before.json`, `comparison-after.json`, `compare-reads.mjs`.
JSON с полными ответами содержит персональные данные, находится вне Git, права 0600.

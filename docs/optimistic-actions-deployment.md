## Что вошло

Срабатывают в момент нажатия; если сервер отказал, экран возвращается к прежнему виду и показывает ошибку.

- **«Не иду, выйти из списка»**: лист закрывается, первый из резерва поднимается в основу (`lib/roster.ts`
  повторяет серверную очередь по порядку записи). При ошибке лист открывается снова с ошибкой у кнопки.
- **Организатор убирает игрока из списка**: строка пропадает, резервист поднимается; при ошибке — тост с именем.
- **Цвет формы во время матча**: лист закрывается, команда перекрашена; при ошибке лист открывается с ошибкой.
- **Переключатель «Уведомления»**: сразу, после запроса разрешения Telegram, если он нужен.
- **Закрепить достижение**, **роль и травма игрока**, **удаление поста в ленте**, **удаление площадки**
  (в «Площадках» и в выборе поля): удалённое при ошибке возвращается на своё место.

Остались с ожиданием ответа: «Встать в резерв» при полной основе (недавно вышедший получает старое место),
формы с серверной проверкой, отмена матча и «Закрыть счёт».

# Match UX Implementation Plan

**Goal:** Make creation, appointment and billing one coherent, accessible flow.
**Architecture:** Existing React/Wouter + native dialog; shared resource refresh; domain lifecycle guards and authenticated group metadata.
**Tech Stack:** React 19, TypeScript, Hono, Drizzle/D1, Vitest, Playwright.
**Spec:** `docs/superpowers/specs/2026-11-04-match-ux-design.md`

## Constraints and decisions

User explicitly asked to fix and implement; proceed in existing `codex/airofit-app` branch and retain pre-existing dirty changes. Do not commit unrelated existing work. No new dependency or migration. Group selection has one real available option. No date-elapsed requirement for billing. Venue optional. Native implementation, independent final review.

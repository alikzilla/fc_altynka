# Back navigation from either edge

Both horizontal inward swipes, starting within 24px of the app canvas edge, invoke the same action as Telegram Back. Root tabs have no back gesture. Sheets own Back while open, including the existing saving lock. Do not use browser history, which could leave the mini-app.

Use a reusable gesture component inside screens and the creation sheet. Share the current Back owner with Telegram. A small arrow follows the finger; a sufficient pull or deliberate flick commits. Short pulls, reversals, vertical motion, multitouch and cancelled touches do not navigate. Preserve native scrolling, form controls, carousel and tab gestures. No permanent edge overlay or added dependency. Reduced motion retains static feedback.

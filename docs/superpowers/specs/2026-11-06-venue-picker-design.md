# Выбор площадки

Согласовано пользователем по интерактивному макету, 6 ноября 2026.

- Назначение игры открывается в нижней шторке поверх матча.
- Поле «Место проведения» открывает вторую шторку. В ней только «Школа Аксай»
  и ссылка пользователя: https://go.2gis.com/G47G5.
- Адрес и стоимость часа неизвестны: показывать «Адрес уточняется», «Цена уточняется».
  При появлении тарифа его формат — «18 000 ₸ / час» в одну строку.
- Выбор применяется явной кнопкой; закрытие сохраняет прежнее значение.
  Время и длительность не сбрасываются. Старые места матчей сохраняются до замены.
- Сохранять название через существующий API `place`, не менять БД и Telegram-сообщения.
- Сохранение блокирует повторную отправку и закрытие. Ошибка сохраняет черновик.
  Поздний ответ после ухода со страницы не должен возвращать пользователя к матчу.
- Поддержать Telegram Back, Escape, фон, свайп, вложенный фокус и обе темы.

## Подход

Использовать существующий ActionSheet для формы и вложенного выбора. Отдельная
страница назначения отклонена пользователем. Нативный select и ручной ввод
не соответствуют согласованному макету. Каталог из одной площадки локален Mini App;
старые строковые значения API совместимы с каталогом.

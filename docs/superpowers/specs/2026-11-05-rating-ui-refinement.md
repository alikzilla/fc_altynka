# Уточнение интерфейса рейтингов

Основание: прямые правки пользователя после просмотра скриншотов 5 ноября 2026.
Это изменение согласованного интерфейса, без нового расчёта рейтинга или миграции.

- Профиль: рейтинг внутри карточки личности; отдельные карточки рейтинга и самооценки
  удалены. Последние матчи остаются. То же представление в шторке другого игрока.
- Начальная анкета: один вопрос за раз; общий slider 1–10 с крупным числом,
  направленной анимацией цифры и прежними пояснениями шкалы. Кнопка Далее закреплена
  над нижней навигацией. Финальный экран стартового рейтинга сохраняется.
- Ревью: карточка вопроса и карточка оценки участников с кнопкой Оценить.
  Кнопка открывает существующую нижнюю шторку. В ней по одному участнику, тот же
  slider, прогресс и пояснения. Затем оценка игры и явная окончательная отправка.
- Выбор не отправляется до явного действия пользователя. В анкете Далее подтверждает
  значение; в ревью движение и отпускание ползунка меняют только оценку. Для перехода к следующему
  участнику нужно нажать Далее; анимация вправо сохраняется. Клавиатура также не запускает
  автопереход — отдельная кнопка подтверждает выбор.
- Можно пропустить участника, вернуться и изменить черновик. Закрытие шторки сохраняет
  оценки в пределах открытой страницы. Ошибка отправки не очищает их.
- Отменённый жест не переключает участника; дополнительный палец игнорируется.
  Reduced motion отключает вращение числа и движение между участниками.
- Анонимность, права, deadline, порог публикации, формула и серверные API сохраняются.

Реализация следует текущим материалам Airofit. Новые зависимости не нужны.

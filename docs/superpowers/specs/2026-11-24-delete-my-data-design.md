# «Удалить мои данные» — дизайн, 24 ноября 2026

Политика конфиденциальности (`/privacy`) обещает: удалим профиль, номер Kaspi, анкету и настройки; в истории
матчей будет «Удалённый игрок», статистика команды не изменится. Эта функция выполняет обещание без участия
администратора.

## Решения пользователя

- Посты ленты, посвящённые игроку (`feed_posts.user_id`), удаляются. В общих постах (церемония, итоги) его имя
  заменяется на «Удалённый игрок».
- Удаление запрещено, только пока игрок — получатель открытого счёта (иначе у счёта пропадёт номер для перевода).
  Собственный долг не мешает: строка счёта остаётся под именем «Удалённый игрок».

## Что происходит

1. Проверка: нет открытого счёта (`bills.status = 'open'`), где он `receiver_user_id` → иначе `409 receiver_open_bill`.
2. Будущие записи отменяются через обычный `leaveEvent` (резерв продвигается, сообщения группы обновляются,
   закрытые матчи `leaveEvent` сам не трогает).
3. Одним `db.batch`:
   - `users`: `tg_id = -id` (повторный вход создаёт новый пустой профиль), имя и отображаемое имя «Удалённый игрок»,
     фамилия, username, Kaspi, фото, позиция, нога, достижение, отметка анкеты, дата напоминания — пусто,
     уведомления и личка — выключены, тема по умолчанию, новый столбец `deleted_at`;
   - удаляются: анкета (`skill_assessments`), календарь (`availability_days`), его реакции и скрытые посты, посты о нём
     (вместе с чужими реакциями и скрытиями этих постов);
   - `memberships`: `active = false`, травма снята — он пропадает из списков групп; строка остаётся для истории;
   - снимки имени: `match_participants.name`, элементы `match_reviews.roster_json` и `events.game_state_json` с его
     `userId`, а в оставшихся постах (`text`, `highlights_json`, `payload_json`) — его имена целыми словами.
4. Сообщения групп пересобираются для матчей, которые ещё не закрыты (`sync.request`).

Остаются, обезличенными: записи на прошедшие матчи, составы, статистика, строки счетов, анонимные оценки и голоса
(их автор и адресат указывают на обезличенную строку `users`; рейтинг других игроков не меняется).

Не меняется: личные сообщения бота, уже доставленные в Telegram, и резервные копии до истечения их срока —
политика говорит об этом прямо.

## API и интерфейс

- `DELETE /api/me` с телом `{ "confirm": "delete" }` → `200 { deleted: true }` | `409 { error: 'receiver_open_bill' }`.
- Профиль → «Системные настройки» → «Удалить мои данные» → лист с тем, что удалится и что останется, и кнопкой
  «Удалить навсегда». После успеха — экран «Данные удалены» с кнопкой «Закрыть» (закрывает мини-апп).

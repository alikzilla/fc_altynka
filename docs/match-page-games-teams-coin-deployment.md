## Поведение

- «Игры»: текущая игра — синяя карточка «Игра N» с дисками формы, очками и чипом «Отдыхают …» / «С мячом начинают …»; без «6 минут». Таблица, последние игры и бомбардиры — графитовые карточки. В истории авторы голов стоят под своей командой, ассистент — в скобках.
- «Начать матч» открывает шторку «Начинаем матч»: сверка цветов (чипы сохраняют цвет сразу) и монета в стиле 200 тенге. Бросок стартует матч; сервер один раз решает, кто отдыхает первым (3 команды) или начинает с мячом (2 команды, новое поле `kickoffTeamIndex`). Ответ появляется после приземления монеты.
- «Составы» для организатора: карточка баланса (2/3 команды, полосы средних, разница, «Перемешать» без подтверждения), обмен двумя тапами, шторка «Форма: команда» на одну команду, панель «Черновик / Опубликованы» с отменой; накануне матча — «Начать матч можно в день игры». Игрок видит свою команду первой с меткой «Твоя команда», без рейтингов.
- Шторка результата: у гола с автором — строка «Пас: выбрать». В профиле «Ассисты» считаются, как только у игрока есть игры с записанными пасами; до этого «—».

## Поведение

Собственный профиль и профиль другого игрока используют согласованную спортивную карточку: увеличенный аватар, эмодзи роли перед Telegram-тегом, непрерывное кольцо рейтинга без подписи, позиция внутри панели статистики. Пять показателей: голы, ассисты, игры, процент побед и рабочая нога в виде стелек. Целые рейтинги показываются без десятичного нуля. Настройки собственного профиля сохранены. В сыгранных встречах убрана повторная плашка даты справа.

Игры и голы считаются по сохранённым протоколам с привязкой к участнику. Уже записанные игры учитываются автоматически; изменение или удаление результата пересчитывает статистику. Ассисты пока равны нулю. Общие показатели учитывают все подходящие встречи, список истории ограничен последними двадцатью. Статистика чужого профиля ограничена общими активными группами.

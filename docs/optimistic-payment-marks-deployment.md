пока ответит сервер. Теперь отметка показывается сразу, а запрос уходит следом.

## Что вошло

- **Галочка организатора и получателя** в «Участники расчёта»: строка и счётчик «Оплату отметили
  X из Y» меняются в момент нажатия. При ошибке галочка возвращается, тост называет игрока.
  Отметки по одной строке уходят на сервер по очереди, в порядке нажатий.
- **«Я перевёл» у игрока**: карточка сразу показывает «Ты отметил оплату». Тост с «Отменить»
  появляется после ответа сервера. При ошибке возвращается кнопка и сообщение под ней.
- Отметка держится до прихода свежего счёта с сервера, поэтому после успеха не мигает обратно.
- Карточка долга покинутой группы (`TaskCard`) по-прежнему ждёт ответа сервера.

# Мини-приложение FC Altynka

React + Vite. Telegram открывает мини-приложение, а Worker раздаёт его сборку и обрабатывает запросы `/api`.

## Где что находится

| Путь | Назначение |
| --- | --- |
| `src/main.tsx` | Инициализация темы, подключение стилей и запуск React |
| `src/App.tsx` | Маршруты, общие провайдеры и окно создания матча |
| `src/components/` | Повторно используемый UI: иконки, карточки, навигация, жест возврата, общие состояния |
| `src/hooks/` | React-хуки загрузки данных и управления нижним окном |
| `src/lib/` | Клиент API, адаптер Telegram, тема, ссылки Kaspi и форматирование подписей |
| `src/screens/` | Экраны и связанные с ними формы, вкладки и секции |
| `src/state/` | Текущий пользователь, уведомления и параметры фонового экрана |
| `src/styles/app.css` | Общие стили интерфейса и адаптивность |
| `src/styles/ratings.css` | Анкета, игровые рейтинги, каталог и профили игроков |
| `src/styles/themes.css` | Цветовые темы и их переопределения |
| `public/` | Статические файлы, включая favicon |
| `test/` | Модульные и компонентные тесты; общий рендер в `render.tsx` |

## Как расширять

- Новый маршрут подключается в `App.tsx`, экран использует общий `Screen` из `components/ui.tsx`.
- Общий компонент помещается в `components/`; содержимое конкретного экрана остаётся в `screens/`.
- Запросы идут через `lib/api.ts`, интеграция с Telegram — через `lib/tg.ts`. Общие типы берутся из `@altynka/core`.
- Используются прямые относительные импорты. При переносе модуля обновляются и импорты тестов, и пути `vi.mock`.
- Общая предметная логика живёт в `packages/core`, серверные операции — в `apps/worker`.

## Команды из корня репозитория

```bash
pnpm --filter @altynka/miniapp dev
pnpm --filter @altynka/miniapp test
pnpm --filter @altynka/miniapp typecheck
pnpm build
pnpm test:ui
```

Vite проксирует `/api` на локальный Worker по адресу `localhost:8787`. Настройка Worker описана в [корневом README](../../README.md).
